# 错误码与状态码

本文整理平台接口的通用响应格式、通用状态码类型和常见业务错误。

平台统一成功判断规则：接口返回的 `code` 为 `1` 或 `200` 表示成功，其他 `code` 一律按失败处理。

## 通用响应格式

平台接口通常返回 JSON，常见结构如下：

```json
{
  "code": 1,
  "msg": "success",
  "data": {}
}
```

| 字段 | 含义 | 说明 |
|------|------|------|
| `code` | 状态码 | `1` 或 `200` 表示成功，其他值表示失败。 |
| `msg` | 状态说明 | 用于展示或记录错误原因。 |
| `data` | 业务数据 | 请求成功时返回业务结果。 |

## 成功判断规则

| `code` | 结果 | 处理方式 |
|--------|------|----------|
| `1` | 成功 | 读取 `data` 字段。 |
| `200` | 成功 | 读取 `data` 字段。 |
| 其他值 | 失败 | 读取 `msg` 字段，按错误类型处理。 |

开发时建议统一封装判断逻辑：

```js
function isSuccess(response) {
  return response && (response.code === 1 || response.code === 200);
}
```

## 通用失败类型

| 失败类型 | 常见含义 | 处理建议 |
|----------|----------|----------|
| 参数错误 | 缺少必填参数、参数格式错误或参数值不合法 | 检查必填参数、字段类型和枚举值。 |
| 密钥错误 | `apikey`、`appkey`、`appsecret` 或签名错误 | 检查密钥类型、应用配置和签名方式。 |
| 权限不足 | 接口未开通、平台未授权或账号权限不足 | 申请接口权限或联系平台人员开通。 |
| 请求方式错误 | 使用了错误的 `GET`、`POST form-data` 或 `POST JSON` 方式 | 按接口类型调整请求方式。 |
| 频率限制 | 调用频率超过当前账号额度 | 降低请求频率、增加重试间隔或申请更高额度。 |
| 数据不存在 | 商品、活动、订单或口令解析结果不存在 | 检查业务 ID、链接、时间范围和平台状态。 |
| 数据不可推广 | 商品、活动或链接不支持推广 | 更换商品/活动，或检查平台推广权限。 |
| 平台同步延迟 | 订单、佣金或活动数据尚未同步完成 | 延迟重试，避免频繁轮询。 |
| 系统异常 | 平台服务异常或上游平台异常 | 记录日志，稍后重试。 |

## 特殊错误提示

| 错误提示 | 可能原因 | 处理建议 |
|----------|----------|----------|
| `apikey验证失败` | 未申请 `apikey`、密钥错误、请求方式错误或接口类型不匹配 | 登录开放平台创建应用并检查请求方式。 |
| `未开通XX官方账号` | 目标平台需要官方账号授权或人工开通权限 | 联系平台人员开通对应平台权限。 |
| 转链失败 | 商品 ID/链接错误、推广位错误、平台未授权或商品不可推广 | 检查商品、推广位、授权账号和权限状态。 |
| 查不到订单 | 订单未同步、时间范围错误、推广链接非当前账号生成或订单权限未开通 | 检查查询条件、推广归因和订单权限。 |
| 口令解析失败 | 口令过期、平台不支持、内容格式错误或接口权限不足 | 检查口令内容和对应平台权限。 |
