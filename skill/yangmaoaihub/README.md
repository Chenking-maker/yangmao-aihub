# 羊毛AIHUB Skill · /yangmaoaihub

把「羊毛AIHUB」装进微信 / QQ 里的 AI 助手：**实时线报自动推送 + 红包每日提醒 + 全链接专属优惠通道**，对话就能薅，不用开网站。

## 它能做什么

| 功能 | 说明 |
|------|------|
| 📡 实时线报推送 | 淘宝 / 京东 / 飞猪 / 百亿补贴 / 宠物 / 美妆六大线报源，有新货秒推。**每天最多 50 条**（默认 20，可自己调） |
| 🔔 关键词 / 类目订阅 | 「订阅纸巾和狗粮」→ 只推你想要的，其余不打扰 |
| 🧧 红包每日提醒 | 每天定时提醒领淘宝超级红包 / 京享红包，直达链接一键领 |
| 🔗 专属优惠通道 | 所有线报、商品、口令自动转成专属优惠链接，你买到的价格不变 |
| 💬 对话找券 | 直接说「找一下纸巾的券」「9.9 以下有什么」，AI 帮你搜 |

## 怎么安装

1. 在**微信或 QQ 里**打开你的 AI 助手对话（需支持安装 Skill）。
2. 发送：`/yangmaoaihub`
3. 按提示确认安装，完成。之后直接对话即可：

```
订阅 纸巾 狗粮 的线报
只订阅淘宝线报，一天最多 10 条
每天早上 9 点提醒我领红包
找一下保温杯的券
```

## 隐私承诺

- **永远不索要你的淘宝 / 京东账号密码。** 领红包、领券点链接即可，无需登录。
- 你的订阅设置只保存在你自己的设备上。
- ⚠️ 任何「输账号密码自动领红包」的工具都有盗号风险，请勿使用。

## 部署者说明（站长）

- Skill 的所有数据请求走羊毛AIHUB 的 API（Cloudflare Worker）。部署方法见仓库根目录 `DEPLOY.md`。
- 接口基地址在 `SKILL.md` 顶部 `API_BASE` 处配置（当前 `https://yangmao-aihub.370542303.workers.dev`，Worker 域名变更时才需要改）。
- 线报源与转链能力由 Worker 提供：`/api/wire`、`/api/convert`、`/api/parse`、`/api/search`、`/api/xhd`、`/api/activities`、`/api/links`、`/api/life/*`。
- 推送默认**不逐条转链**（几十条要等几分钟）；只在用户明确要求或直接发链接时才转 —— 同一链接二次转链有缓存，毫秒级返回。
