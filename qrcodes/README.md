# 微信群二维码上传说明

微信群页面（wechat.html）的二维码全部由你本人上传，网站只负责展示。

## 上传步骤

1. 把微信群二维码图片（PNG/JPG 均可，建议正方形、不小于 300×300）复制到本目录 `site/qrcodes/`
   - 例如：`group1.png`、`group2.png`
2. 编辑同目录下的 `groups.json`，按下面格式加一条：

```json
{
  "groups": [
    {
      "name": "羊毛AIHUB 交流群①",
      "qr": "qrcodes/group1.png",
      "desc": "线报同步 / 互助凑单 / 红包提醒",
      "tag": "活跃"
    }
  ]
}
```

3. 保存后刷新 wechat.html 即可看到（本地开发）或推送 GitHub 后生效（线上）。

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| name | 是 | 群名称，显示在二维码下方 |
| qr | 是 | 图片路径，相对站点根目录，通常是 `qrcodes/文件名.png` |
| desc | 否 | 群介绍一句话 |
| tag | 否 | 小角标，如「活跃」「新群」「满员」 |

## 注意

- 微信群二维码有效期只有 7 天，过期了换一张图、改一下文件名，再更新 groups.json 里的路径。
- 图片文件名建议用英文/数字，避免中文名在某些环境下编码出错。
- 想加多个群就按格式多加几条，页面会自动排版。
