📲 怎么安装（两分钟搞定）

Skill 要装在「支持 Skill 的 AI 助手」里。下面三条路径按推荐程度排序，想直接在微信里用的，走路径一。

推荐 · 微信里直接聊

路径一：微信 ClawBot（微信官方 AI 插件）

这是目前唯一能在微信聊天窗口里直接调用 Skill 的官方通道：把 AI 助手（OpenClaw / QClaw）绑定到微信，之后在微信里发一句话就能装、发一句话就能用，不用开网站、不用装 App。

  1. 电脑装 QClaw：打开 qclaw.qq.com 下载安装（已部署 OpenClaw 可跳过这步）。
  2. 微信启用 ClawBot 插件：微信 → 我 → 设置 → 插件 → 找到 ClawBot → 启用。（灰度放量中，没看到入口就把微信升级到 8.0.70 以上，杀掉进程重开；安卓用户也可在 QClaw 里直接找微信绑定入口扫码）
  3. 装微信通道：插件详情页点「详细」复制安装命令，在电脑终端执行：
    npx -y @tencent-weixin/openclaw-weixin-cli@latest install
  4. 扫码绑定：终端弹出二维码 → 微信「扫一扫」→ 确认授权。微信联系人里会出现「微信ClawBot」。
  5. 装羊毛AIHUB：在微信 ClawBot 聊天窗直接发一句话：
    「安装 yangmaoaihub」——它会自动找到并装上，全程不用碰电脑。

💡 如果微信里回复「没找到这个技能」：Skill 还没上架技能市场，在跑 ClawBot 的电脑终端补一条命令即可（装的就是本仓库里的 Skill 本体）：
npx --yes skills add https://github.com/Chenking-maker/yangmao-aihub/tree/master/skill/yangmaoaihub -a openclaw -y
装完回到微信，直接说「订阅纸巾线报」就能用了。

备用 · 零门槛

路径三：任意 AI 助手（元宝 / DeepSeek / 豆包 / Kimi…）

把下面这条消息发给任意一个 AI 助手，它会按 Skill 说明每天帮你整理线报、提醒红包：

安装羊毛AIHUB Skill：https://github.com/Chenking-maker/yangmao-aihub/tree/master/skill/yangmaoaihub

这类 App 大多没有真正的「Skill 安装」机制，实际是让 AI 按说明文档执行；能否定时推送取决于 App 自身的提醒能力。要完整体验请走路径一或路径二。
