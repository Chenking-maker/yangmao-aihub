# /yangmaoaihub Skill 使用教程（微信 / QQ）

> 把羊毛AIHUB 装进微信 / QQ 的 AI 助手里，发一句命令就能用，不用开网页。

## 它能做什么

| 功能 | 说明 |
|------|------|
| 📡 **实时线报推送** | 六大类目（淘宝/京东/飞猪/百亿补贴/宠物/美妆）实时监控，有新货直接推给你，**每天最多 50 条**（默认 20，可自定） |
| 🔑 **关键词 / 类目订阅** | 「订阅纸巾和狗粮」「只推淘宝线报」，只发你关心的 |
| 🔗 **优惠链接直达** | 推出来的口令和链接，全部已转好，点开就能领券下单 |
| 🧧 **红包每日提醒** | 定时提醒领双11 红包，一键直达，绝不漏领 |

## 安装步骤（微信 / QQ 通用）

1. 打开微信或 QQ 里的 **AI 助手**（支持第三方 Skill 的版本）
2. 在对话框输入并发送：**`/yangmaoaihub`**
3. 按提示点击 **安装**，等出现「羊毛AIHUB Skill 已就绪」
4. 发一句「订阅 双11红包 + 纸巾 + 狗粮」设置你想看的内容
5. 完成！之后有新线报 / 红包提醒会直接在对话里推送

## 常用指令示例

```
/yangmaoaihub                      # 安装 / 唤起
订阅纸巾、狗粮、纯牛奶              # 设置关键词订阅
只推淘宝线报                        # 只看某个类目
每天最多推 50 条                    # 调整推送上限
今天有什么红包                      # 手动触发红包提醒
```

## 隐私说明

- Skill **不需要也不存储**你的淘宝/京东账号密码
- 领红包不需要密码：推送的链接点开即达官方页面
- 请勿向任何人（包括 AI 助手）提供账号密码、验证码
